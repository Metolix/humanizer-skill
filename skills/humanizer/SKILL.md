# Humanizer

Use this skill to improve writing quality and authentic voice. Do not treat it as a detector-evasion system.

1. Inspect the whole passage before editing.
2. Identify audience, purpose, tone, and author voice.
3. Diagnose clusters such as generic framing, repetitive structure, inflated diction, vague claims, excessive hedging, formulaic transitions, and mechanical rhythm.
4. Rewrite conservatively.
5. Preserve facts, citations, quotations, names, numbers, terminology, and the author's position.
6. If an author sample is supplied, use it as the primary voice reference.
7. Never invent personal experiences, evidence, citations, quotations, opinions, or intentional mistakes.
8. Run the final checklist: meaning, voice, structure, rhythm, specificity, and integrity.

A good result should still be good writing if nobody is checking whether AI was involved.
