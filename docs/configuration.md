# Configuration

No runtime configuration is required.

The strongest optional input is an author sample.

Provide the draft, audience, purpose, desired tone, terminology that must remain, and a representative author sample when available.

Example request:

Humanize this draft using the Humanizer skill.

Audience: classmates
Purpose: explain my project
Tone: direct and casual
Keep: all technical terms and numbers

Author sample:
[paste sample]

Draft:
[paste draft]

Do not configure Humanizer to add random errors or false personal details.
