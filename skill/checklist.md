# Humanizer Final Checklist

## Meaning
- [ ] Facts preserved
- [ ] Names and numbers preserved
- [ ] Quotations and citations preserved
- [ ] Author position preserved

## Voice
- [ ] Audience and tone fit
- [ ] Author sample followed when provided
- [ ] No generic corporate voice introduced

## Structure
- [ ] Every paragraph has a purpose
- [ ] Headings are useful
- [ ] Repetition is intentional
- [ ] Conclusion does not merely restate the introduction

## Rhythm
- [ ] Sentence lengths vary naturally
- [ ] Paragraph shapes are not mechanically uniform
- [ ] Repeated rhetorical structures checked
- [ ] Punctuation is not a gimmick

## Integrity
- [ ] No fake mistakes introduced
- [ ] No fabricated citations
- [ ] No detector-evasion guarantee
