# Contributing

Good contributions add evidence, improve the core rules, document a failure case, improve portability, add regression cases, or clarify installation.

Avoid contributions that simply add lists of banned AI words. Context matters and humans use those words too.

## Pull requests

Include what changed, why it changed, supporting examples or evidence, compatibility implications, and updated tests or documentation when relevant.

Keep changes focused.

## Research

Prefer primary or peer-reviewed sources. Clearly label vendor claims and include limitations. Do not turn correlations into universal rules.
